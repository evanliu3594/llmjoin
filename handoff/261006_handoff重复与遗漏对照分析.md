## 外部技能的设计要点
1. 定位：把当前会话压缩成一份交接文档，交给下一个新 agent；写到系统临时目录，不进工作区。
2. 不复制其他载体已有的内容（specs、plans、ADRs、issues、commits、diffs），只给路径或 URL 引用。
3. 按调用参数裁剪：文档只服务下一个会话的用途。
4. 文档内写 suggested skills 一节，点名下一个 agent 应加载的技能。
5. 落盘前脱敏；由用户在会话收尾时手动触发，非每任务自动留痕。
